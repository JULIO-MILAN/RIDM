## 📖 Descripción del Proyecto

**Recolectora Integral de Desechos de México (RIDM)** es una empresa dedicada a los servicios de recolección, gestión y reciclaje de residuos con cobertura en CDMX, Estado de México, Hidalgo, Morelos y Querétaro.

Este proyecto consiste en el desarrollo de una **plataforma web corporativa** y un **brochure digital** que reflejan la identidad visual de la empresa y facilitan la comunicación de sus servicios con clientes potenciales.

## 🌐 Sitio Web Corporativo

El sitio web incluye las siguientes secciones:

- **Inicio** — Presentación principal con llamada a la acción
- **Nosotros** — Información de la empresa
- **Por Qué Elegirnos** — Diferenciadores de RIDM
- **Servicios** — Catálogo completo de servicios de recolección y gestión de residuos
- **Cómo Trabajamos** — Proceso de trabajo con el cliente
- **Materiales** — Tipos de materiales que se recolectan y reciclan
- **Sostenibilidad Creativa** — Iniciativas de arte y reutilización
- **ECOShop** — Tienda de productos sustentables
- **Cobertura** — Zonas de servicio
- **Contacto** — Formulario y datos de contacto

---

## 📄 Brochure Digital

El brochure es una pieza comercial diseñada para presentación a clientes corporativos, con información resumida de servicios, diferenciadores y datos de contacto directo.
